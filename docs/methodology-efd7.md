# 效果漏斗拆解法 EFD-7

**Effect Funnel Deconstruction · 七层可验证广告素材理解框架**

用于图片 / 视频广告素材的内容理解。输出须让设计师认同、可复盘、可据此写出复刻与迭代提示词。

---

## 1. 为什么需要一套新方法论

行业里常见碎片：

| 来源 | 贡献 | 缺口 |
|------|------|------|
| Motion / Meta 创意诊断 | 停滑、留存、钩子 | 偏指标，缺叙事与视听拆解 |
| PAS / AIDA / 4P | 说服顺序 | 不绑定画面证据与投放漏斗 |
| 好莱坞 7-Beat / Save the Cat | 节拍与张力 | 不为效果广告的 CTR/转化服务 |
| 摄影指导 / 灯光构图清单 | 视听语言 | 易沦为「好看但无效」 |
| 纯 LLM 看图描述 | 表面语义 | 不可验证、难说服设计与投放 |

**EFD-7** 把以上融合为一套**按效果影响力排序**的漏斗：上层不及格，下层再精美也不能用「调色好看」救投放。每一层强制：**可观测问题 → 画面/字幕/口播证据 → 判定 → 指标代理 → 改进动作**。

---

## 2. 核心原则（可被人验收）

1. **影响力序**：L1→L7 固定；分析与报告必须同序。禁止先堆摄影术语再补钩子。
2. **证据优先**：每层至少 1 条可指认证据（时间点 / 字幕原文 / 景别变化 / 口播句）。无证据则 `verdict=unknown` 或降级，禁止空话。
3. **漏斗否决权**：若 L1 或 L2 为 `fail`，摘要必须写明：「下层（视听/台词）优化的边际收益低于先修钩子/认同」。
4. **双输出分离**：① 理解稿（本方法）→ ② 命名（知识库规范）。命名不得替代理解。
5. **可复刻闭环**：L7 必须产出 `must_keep`、`variables_to_test`、可直接粘贴给生成/拍摄的 `iteration_prompt`。
6. **可验证**：`score` 1–5；`verdict` ∈ {pass, weak, fail}；`metric_proxy` 写投放侧可对照的代理指标。

---

## 3. 七层定义（顶层 → 细节）

### L1 注意力捕获 · 影响力 7/7

- **问题**：前 1–3 秒是否停滑？是否立刻知道「在讲什么」？
- **心理学**：新奇 / 冲突 / 自我相关 / 未完成完形（Zeigarnik）
- **证据举例**：开场字幕原文；首帧主体；突变声画；人脸/产品入画时机
- **metric_proxy**：钩子率 / thumbstop / 3s 播放率
- **fail 典型**：美但无议题；产品晚入画；开篇堆氛围

### L2 对象认同 · 影响力 6/7

- **问题**：目标人群是否觉得「这是说我」？
- **心理学**：社会认同、角色投射、场景镜像（场景≈用户生活切片）
- **证据举例**：人设年龄/性别/体型；场景（通勤/居家/运动）；痛点措辞是否对圈层
- **metric_proxy**：前段留存、跳失前的共鸣段时长
- **fail 典型**：模特/场景与投放受众错位；泛人群口号

### L3 叙事说服结构 · 影响力 5/7

- **问题**：痛点/欲望 → 加剧 → 方案 → 证明 → 行动是否完整？
- **融合框架**：
  - **PAS**：Problem → Agitate → Solution
  - **AIDA**：Attention → Interest → Desire → Action（映射到节拍）
  - **7-Beat（广告改写）**：Opening → Context → Tension → Delivery → Validation → Shift → Close
- **证据举例**：各节拍起止秒；缺失的节拍名
- **metric_proxy**：中段 hold、完整观看率
- **fail 典型**：只有卖点罗列；无 Tension；过早硬广

### L4 信任与证据 · 影响力 4/7

- **问题**：主张是否可信？
- **证据类型**：演示、前后对比、材质/工艺特写、数据/口碑、质感与真实感
- **心理学**：权威 / 社会证明 / 具体性（concrete > abstract）
- **metric_proxy**：CTR 前停留、互动但不点出的「犹豫段」
- **fail 典型**：口头宣称无画面证明；假对比；证据与卖点脱节

### L5 视听语言 · 影响力 3/7

- **问题**：灯光、构图、景别、运镜、转场、节奏是否**服务说服**（而非炫技）？
- **清单**：
  - 灯光：主光/辅光/轮廓；是否分离主体与背景
  - 摄影：景别序列（全→中→特）；推拉摇移是否有信息增量
  - 构图：主体占比、视觉重心、负空间是否留给字幕
  - 转场：切/叠/动作匹配；是否掩盖逻辑跳跃
  - 节奏：剪辑密度是否「前紧（钩子）后证（证据）」
- **metric_proxy**：掉点时间戳与镜头切换是否重合
- **规则**：L5 不得单独评为「优秀」若 L1–L4 偏弱——只记「技术可保留变量」

### L6 信息与台词 · 影响力 2/7

- **问题**：口播、字幕、CTA 是否清晰，且与落地页承诺一致？
- **证据**：口播原文；屏显字；CTA 时机与措辞；合规风险词
- **metric_proxy**：CTR、落地跳出（承诺不一致时）
- **fail 典型**：字太多；口播与字幕打架；CTA 缺失或过晚

### L7 可复刻变量 · 影响力 1/7（对组织最有用）

- **问题**：必须保留什么？可测什么？下一版提示词怎么写？
- **输出**：
  - `must_keep`：商品识别、核心卖点、品牌调性红线
  - `variables_to_test`：钩子句式 / 证据形式 / CTA / 人设 / 时长
  - `iteration_prompt`：150–400 字，可直接给设计师或生成模型的拍摄/生成 brief

## 4. 视频专用：节拍表（Beats）

视频理解除 L1–L7 外，必须输出时间轴节拍（可裁剪为实际出现的子集）：

| Beat | 秒级参考 | 意图 |
|------|----------|------|
| Opening | 0–3s | 停滑 + 立议题 |
| Context | 3–8s | 这是谁的世界 |
| Tension | 中前 | 缺口/痛点加剧 |
| Delivery | 中 | 产品作为方案入画 |
| Validation | 中后 | 证明可信 |
| Shift | 近末 | 认知或情绪转向 |
| Close | 末 3–5s | CTA / 记忆点 |

静帧 / 单图：beats 可压缩为 1–2 个「信息层级」（主视觉 → 卖点字 → CTA）。

---

## 5. 分析流程（人工或 AI 同序）

```
抽帧/看片 → 一句话 one_liner（卖什么、怎么卖）
  → L1…L7 逐层：问题→证据→score/verdict→improve
  → 填 beats / craft / script
  → L7 replication_brief
  → summary_markdown（给人读）
  →（下游）基于理解 + 知识库 → 命名字段
```

**否决检查**：若 L1=fail，iteration_prompt 必须以「先重做前 3 秒」开头，不得只写调色/运镜。

---

## 6. 判定量表（统一口径）

| score | verdict | 含义 |
|-------|---------|------|
| 5 | pass | 可复刻为标杆 |
| 4 | pass | 达标，小改即可测 |
| 3 | weak | 有结构但证据或执行弱 |
| 2 | fail | 明显拖累漏斗 |
| 1 | fail | 该层失效，优先重做 |

---

## 7. 设计师验收清单

- [ ] 七层齐全，顺序正确，每层有证据  
- [ ] one_liner 与画面商品一致  
- [ ] 视频有节拍；视听与台词栏非空话  
- [ ] 认同「上层差则下层救不了」的表述（若适用）  
- [ ] 能直接用 `iteration_prompt` 开下一版，且 `must_keep` 不丢卖点
