# 素材理解方法论：三层碎镜理解法（FCJ）

**Fact → Cognition → Judgment · 以分镜（Clip）为最小单位的广告素材理解框架**

目标：任何一条图片 / 视频素材上传后，系统都能回答——**哪个素材的第几秒是什么镜头、在广告里起什么作用、为什么有效、应该怎么用、怎么改**。设计师可以直接据此复刻、微调，AI 可以据此混剪，不再手工拆镜头、手工打标。

---

## 0. 为什么分三层

广告素材分析最常见的问题是「描述、分析、评价」混在一起：一句「开头很抓人」既不是事实，也无法验证。FCJ 把理解拆成三层，**每一层只做一件事，下一层只能引用上一层**：

| 层 | 只做什么 | 不做什么 | 谁会认同 |
|----|----------|----------|----------|
| 事实层 Fact | 记录看得见、听得到的内容 | 不评价、不分析 | 导演、摄影、剪辑：能逐镜核对 |
| 认知层 Cognition | 用广告科学框架解释「这条物料用什么机制影响用户」 | 不打分、不提建议 | 策划、投放：结论都能回指分镜 |
| 判断层 Judgment | 结合历史投放数据预估效果，给分镜级微调方案 | 不推倒重来 | 负责人、设计师：理由可追溯、改动可执行 |

可验证性来自三条硬约束：

1. **分镜由程序切，不由 AI 猜。** 浏览器逐帧计算画面突变，得到精确到 0.1 秒的分镜边界；AI 只能按这些 id 和时间段填内容，不得增删合并。
2. **引用链。** 认知层每条结论都要带分镜 id（C01…）或对象编号（商品 G1、人物 P1、场景 S1）；判断层每条理由都要带分镜 id + 事实原文 + 历史数据。
3. **统计先验做锚。** 效果预估以本账户同标签素材的真实 ROAS / 消耗为起点，创意因素只能做有理由的修正。

## 1. 预处理：自动切镜（碎镜）

| 步骤 | 做法 |
|------|------|
| 采样 | 按 0.2s（长视频自适应）逐帧采样，缩到 48×27 |
| 差分 | 像素绝对差 + RGB 直方图差，各占一半 |
| 判切点 | 差值 > max(0.12, 全片中位数 × 4)，且是局部峰值，且与上一切点间隔 ≥ 0.45s |
| 长镜头 | 单镜头超过 5s（如整段口播）拆成 ≤5s 的「同镜头续段」，标记 `cont`，便于逐段理解与混剪 |
| 关键帧 | 每个分镜取中点帧送 AI，另存 200px 缩略图用于界面 |
| 口播 | 视频文件 ≤24MB 时调用语音转写（whisper），台词以带时间戳的转写为准 |

## 2. 事实层 Fact —— 编导视角，只记录

角色设定：广告片导演兼场记（script supervisor），像开机前给剧组各部门出拍摄通告和分镜表。

**输出结构：总述 + 核心模块 / 打标 + 横向分镜拆解**

- **总述**：3–5 句纯事实（什么形式、谁、在哪、做了什么、展示了什么、如何收尾）
- **形式**：画幅、时长、风格（实拍剧情 / UGC 口播 / 产品展示 / 混剪 / 图文）、声音构成、分镜数、平均镜长
- **核心模块**（编号去重，不缺不漏）
  - 商品 G1…：名称、外观、展示方式与部位、出现分镜、首次出现时间
  - 人物 P1…：数量、性别、年龄段、外形、服装、角色、出现分镜
  - 场景 S1…：名称、内外景、时间、道具、出现分镜
  - 声音：口播者与语气、音乐风格与节奏、音效
  - 台词脚本：按分镜归位的口播 / 字幕原文
  - 字幕特效：原文 + 位置 / 字体 / 颜色 / 动效
  - 关键词与打标：商品、人物、场景、景别、运镜、灯光、色调、字幕、音频、形式
- **剧组岗位视角**（复刻准备清单）：导演/编剧、摄影指导、灯光、美术/道具、服装/化妆、演员/调度、剪辑/包装、录音/音乐
- **分镜拆解**（横向排列，每镜一卡）：景别、机位角度、运镜、焦段、灯光（光位/光质/色温/明暗变化）、构图与景深、主体与动作（起势→过程→落点）、出镜商品及部位、人物、场景、台词、字幕、特效、入点转场、色调

禁止词：吸引人、高级、有效、不错……任何判断性形容词都不属于事实层。看不清就写「不可辨」。

## 3. 认知层 Cognition —— 广告机制，只分析

角色设定：Meta 效果广告创意策略总监。把事实翻译成「这条物料用什么机制影响谁」，**不评价好坏**。

| 模块 | 回答的问题 | 依据的方法论 |
|------|-----------|-------------|
| 定位 | 用什么方式、向谁、卖什么 | — |
| 核心吸引力 | 用户为什么会停下来（痛点共鸣 / 反差 / 好奇缺口 / 利益承诺 / 视觉奇观 / 社会证明 / 人物魅力 / 价格刺激） | 注意力心理学 |
| 卖点 | 商品能提供什么：主卖点 + 次卖点，各自的特征→优势→利益与表达方式 | FAB |
| 买点 | 用户为什么想买：要完成的任务、动机层级、情绪及强度、情绪走向、氛围 | JTBD、马斯洛、Plutchik 情绪轮 |
| 受众 | 画像、认知阶段（无意识 / 问题意识 / 方案意识 / 产品意识 / 最知晓）、市场成熟度、使用场景 | Schwartz《Breakthrough Advertising》 |
| 说服机制 | 叙事结构（PAS / AIDA / BAB / 问题-演示-结果）、信息加工路径（中心 / 边缘）、影响力原则、证据类型 | ELM、Cialdini |
| ABCD | 注意力、品牌露出、情感连接、行动指令各由哪些分镜承担 | Google ABCD（Kantar 验证与短期销量相关） |
| 行为触发 | 动机、能力（降低门槛的信息）、提示 | Fogg B=MAP |
| 投放适配 | 前 3 秒、无声可读、竖版、原生感 | Meta 创意最佳实践 |
| **分镜功能** | 每个分镜的角色（Hook / Context / Problem / Agitate / Demo / Proof / Benefit / Offer / CTA / Brand / Bridge）、作用、心理机制、混剪可复用位置 | 以上综合 |

**卖点 ≠ 买点**：卖点是商品视角（面料透气），买点是用户视角（通勤一整天不狼狈）。好的素材用卖点去证明买点。

「分镜功能」是混剪的基础数据：AI 后续可以按「开头钩子 / 中段证明 / 结尾转化」从素材库中直接调取对应秒段。

## 4. 判断层 Judgment —— 效果预估与微调

角色设定：Meta 投放效果分析师 + 广告导演。

### 4.1 统计先验（程序计算，不由 AI 编）

1. 取本账户所有已回流、有消耗的素材，计算账户整体 ROAS、单素材消耗分位数。
2. 找出与本素材**相同命名标签 / AI 标签**的历史素材组，取每组的 ROAS、消耗、素材数。
3. 先验 ROAS = 账户均值 × exp(0.6 × Σ wᵢ·ln(ROASᵢ/均值) / Σ wᵢ)，wᵢ = min(1, 样本数/5)。样本少的标签权重低，整体再向均值收缩 40%，避免小样本过拟合。
4. 消耗档位按同标签素材的单素材消耗落在账户分位的位置：S ≥ P90、A ≥ P70、B ≥ P40、其余 C。
5. 同时给出 3 条消耗过中位数的高 ROAS 参照素材。

### 4.2 AI 判断

- **预估**：消耗档位、ROAS 区间、相对账户均值（高于 / 持平 / 低于）、置信度。以先验为锚，每一处上调或下调都必须能在「拉高 / 拖累因素」中找到对应条目。无历史数据时置信度不超过 0.5。
- **效果漏斗诊断（EFD-7）**：按对效果的影响力从上到下逐层打分——L1 注意力、L2 对象认同、L3 叙事说服、L4 信任与证据、L5 视听语言、L6 信息与台词、L7 可复刻变量。上层不及格时，下层精修的边际收益很低。
- **拉高 / 拖累因素**：每条写明分镜 id、事实原文、对应的历史数据（没有就标「创意规律」）、影响程度。
- **微调方案**（最多 5 条，总改动 ≤ 全片 30%）：分镜、秒段、类型（分镜替换 / 台词 / 字幕 / 场景 / 节奏 / 音乐 / CTA / 调色）、原内容 → 改为、理由、影响的指标。
- **视频生成提示词**（中 / 英）：必须继承事实层中该分镜及前后分镜的人物外观与服装、商品外观、场景道具、灯光、色调、画幅、时长，保证与原片无缝衔接。结构固定为：

  > 主体与外观｜动作（起势→过程→落点）｜场景与道具｜镜头（景别 / 角度 / 运镜 / 焦段）｜灯光与色调｜时长与画幅｜风格质感｜负面约束（无文字水印、肢体不变形、商品外观与 logo 不改变）

- **保持不动**：明确哪些分镜和要素不能动。

## 5. 产品形态

- 编辑页以视频为中心：左侧播放器 + 分镜时间轴（按分镜功能着色），右侧「内容理解 / 素材命名」两个模块切换。
- 内容理解下分「事实层 / 认知层 / 判断层」三个子页；点击任意分镜编号、时间轴色块或关键帧，视频都会跳到对应秒数。
- 命名在认知层之后生成，使用理解摘要 + 知识库规范；判断层在命名之后生成，用命名标签匹配历史数据。
- 「复制理解（Markdown）」可直接交给设计师或下游 AI。

调用顺序：自动切镜 → 语音转写 → 事实层 → 认知层 → 命名 → 历史基准 → 判断层。

---

## 6. 设计师验收清单

- [ ] 分镜时间与实际画面吻合；商品 / 人物 / 场景无遗漏、无重复
- [ ] 事实层没有任何评价词
- [ ] 认知层每条结论都能点回具体分镜
- [ ] 判断层的预估能看到历史依据，修正理由与因素条目一一对应
- [ ] 微调方案改动小、可定位；提示词可直接粘贴到视频生成模型，生成结果与前后镜衔接
